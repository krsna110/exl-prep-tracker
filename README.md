# EXL Prep Tracker

An interactive 28-day preparation and study tracker tailored for EXL interview preparation covering Python, SQL, Machine Learning, NLP, RAG, and Cloud technologies.

## 🚀 Live Demo
- **Live Tracker App:** [https://krsna110.github.io/exl-prep-tracker/](https://krsna110.github.io/exl-prep-tracker/)

## 📋 Features
- **28-Day Structured Plan:** Organized into weekly modules (Python, SQL, ML fundamentals, NLP, LLMs, and RAG).
- **Project Milestones:** Dedicated tracking for hands-on Insurance RAG Assistant project.
- **Progress Tracking:** Dynamic completion percentage and progress bar.
- **Local Persistence:** Automatically saves your checked tasks in browser `localStorage`.
- **Dark / Light Mode Support:** Adapts seamlessly based on system theme or preferences.

## 💻 Tech Stack
- Pure HTML5, CSS3, and Vanilla JavaScript (Zero external dependencies).
- Hosted on GitHub Pages.
